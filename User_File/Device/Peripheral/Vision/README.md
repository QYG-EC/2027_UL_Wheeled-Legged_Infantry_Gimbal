# 24字节视觉串口接口

整体控制逻辑、协议字段与调参位置统一见[自瞄控制与参数说明](../../../../docs/AUTOAIM_CONTROL.md)。
协议依据用户提供的《没有加mpc的串口协议_电控对接.md》，替换旧V2的32字节参考和定点反馈。

正式GimbalBoard由BoardConfig绑定串口1（PA9发送、PA10接收），运行期使用
`vision.h::VISION_BAUD_RATE`，默认921600 bit/s、8数据位、无校验、1停止位、无流控。
独立辨识应用不加载本模块；复用已有非阻塞中断收发，无新增任务或动态内存。

两方向均为24字节，FF头、0D尾，多字节字段采用大端序；float32直接表示rad、rad/s、m、m/s。
当前无CRC（Cyclic Redundancy Check，循环冗余校验），反馈预留校验填0。
`vision.cpp`维护固定长度和字段偏移，双方必须同步升级，不兼容旧FE帧头协议。

`Vision_ReadLatest`原子读取同一完整帧，包含目标绝对角、距离、编号、敌方自转速度、
开火建议、本地主控接收ms与递增序号。应用坐标Yaw左转正、Pitch抬头正，Pitch仅在收发边界反号。
不提供云台参考速度、加速度；敌方自转不能用作本机前馈。

帧头尾错误或任一浮点数非有限时不更新快照；`target_state=1`且距离>0才为有效参考。
无目标发布撤销状态、清角度和开火建议、距离设为−1，不作为回零命令。
固定长度拼接支持拆帧、粘帧及错误后重同步，合法载荷中的FF/0D不分隔帧。
读取不会刷新接收时间。接收解析不切换模式、不控制电机、不触发射击。

`GimbalInput_Update`在控制任务适配参考并交给仲裁；CH8许可下CH7请求自瞄。
反馈由同份外置惯性姿态编码，默认10ms周期、1000ms姿态时效、16m/s固定弹速，
参数均在`gimbal_input.h::Struct_Gimbal_Input_Config`修改后重新编译。
反馈保留原姿态时间戳，串口忙跳过，不排队或重试；初始化失败沿用现有失败记录。

`python3 tests/run_gimbal_link.py`验证实际协议与控制代码，硬件使用桩。
尚需实机核对实际串口收发、坐标参考系、正方向及控制周期耗时。
